# OTCLIENT V8 - LLM CONTEXT DOCUMENTATION

This document provides complete context for understanding and working with OTClient V8.

## 1. PROJECT ARCHITECTURE

OTClient V8 is an Open Tibia game client written in C++ with a Lua scripting layer.

### Directory Structure
```
d:\TIBIA\_REAL_PROJECT\V8\
├── src/                    # C++ source code (client core)
│   ├── framework/          # Base framework (287 files)
│   │   ├── ui/            # UI system (UIWidget, UIManager, layouts)
│   │   ├── graphics/      # Graphics pipeline (OpenGL, textures, shaders)
│   │   ├── otml/          # OTML/OTUI parser
│   │   ├── luaengine/     # Integrated Lua engine
│   │   ├── net/           # Networking
│   │   ├── sound/         # Audio system
│   │   └── platform/      # Platform abstraction
│   ├── client/            # Client-specific logic (89 files)
│   │   ├── creature.cpp/h # Creatures and players
│   │   ├── localplayer.*  # Local player (walking, stats, etc.)
│   │   ├── map.cpp/h      # Map system
│   │   ├── mapview.cpp/h  # Map rendering
│   │   ├── tile.cpp/h     # Map tiles
│   │   └── ui*.cpp/h      # Game-specific widgets
│   └── main.cpp           # Entry point
├── modules/               # Lua modules (55 modules)
│   ├── corelib/          # Core Lua library
│   ├── gamelib/          # Game Lua library
│   ├── client_*/         # Client modules
│   └── game_*/           # Game modules
├── data/                  # Game data (sprites, items, etc.)
├── layouts/               # Visual layouts (retro, mobile)
├── mods/                  # Optional mods
└── init.lua              # Main startup script
```

## 2. LUA MODULE SYSTEM

### Module Structure
Each module folder contains:
- name.otmod (definition), name.lua (code), name.otui (UI, optional)
- styles/*.otui, widgets/*.lua (optional)

### .otmod Format
```otml
Module
  name: module_name
  description: Description
  author: Author
  sandboxed: true
  reloadable: false
  autoload: true
  autoload-priority: 500    # 0-99: libs, 100-499: client, 500-999: game, 1000+: mods
  scripts: [file1, file2]
  load-later: [other_module]
  @onLoad: init()
  @onUnload: terminate()
```

### Module Functions
```lua
g_modules.discoverModules()       -- Discover all modules
g_modules.autoLoadModules(999)    -- Load modules up to priority
g_modules.ensureModuleLoaded("x") -- Ensure module is loaded
g_modules.getModule("name")       -- Get module reference
g_modules.unloadModules()         -- Unload modules
g_modules.reloadModules()         -- Reload modules
```

### Module Example
```lua
function init()
  connect(g_game, { onGameStart = onGameStart })
  g_ui.loadUI('my_module')
end

function terminate()
  disconnect(g_game, { onGameStart = onGameStart })
  myWidget:destroy()
end
```

## 3. OTUI SYSTEM

OTUI (Open Tibia User Interface) is a declarative UI system using .otui files.

### Basic Syntax
```otui
WidgetName < ParentType
  id: myId
  size: 200 100
  text: "Hello"
  image-source: /path/img
  anchors.fill: parent
  anchors.centerIn: parent
  
  UIWidget
    id: childWidget
```

### Base Widget Types (C++)
UIWidget, UIWindow, UIButton, UILabel, UITextEdit, UICheckBox, UIScrollArea, UIScrollBar, UIProgressBar, UIComboBox, UITabBar, UIGridLayout

### Game-Specific Widgets
UIGameMap, UIItem, UICreature, UIMinimap, UIGraph, UISprite, UIProgressRect

### Lua Widgets (corelib/ui/)
UIMiniWindow, UIMiniWindowContainer, UIMovableTabBar, UIPopupMenu, UIInputBox, UIMessageBox, UISpinBox, UITable, UIRadioGroup, UIResizeBorder, UISplitter

### Main Properties
```
# Dimensions: size, width, height, min-width, min-height, max-width, max-height
# Position: position, margin(-top/right/bottom/left), padding(-top/right/bottom/left)
# Appearance: opacity, color, background-color, visible, enabled, focusable, phantom, clipping, rotation
# Image: image-source, image-clip, image-color, image-border, image-repeated, image-smooth, image-offset
```

## 5. WALKING SYSTEM

Files: modules/game_walking/walking.lua, src/client/localplayer.cpp

### Concepts
- preWalk: Predictive movement before server confirmation
- serverWalk: Server-confirmed movement
- smartWalk: Key combination for diagonals
- walkLock: Temporary movement block
- dash: Fast mode without waiting

## 13. CUSTOM WIDGETS

```lua
UIMyWidget = extends(UIWidget, "UIMyWidget")

function UIMyWidget.create()
  local widget = UIMyWidget.internalCreate()
  widget.customValue = 0
  return widget
end

function UIMyWidget:onStyleApply(styleName, styleNode)
  for name, value in pairs(styleNode:asTable()) do
    if name == 'my-custom-property' then self:setCustomValue(tonumber(value)) end
  end
end

-- Register in .otmod: scripts: [widgets/my_widget]
-- Use in OTUI: UIMyWidget { id: widget; my-custom-property: 50 }
```
